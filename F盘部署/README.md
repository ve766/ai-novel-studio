# F 盘安装包

此部署包用于 Windows x64。`一键安装到F盘.bat` 会先检查 F 盘、创建 `F:\ai小说` 文件夹，再打开安装程序；安装过程中仍由你确认并完成安装。安装程序默认位置为 `F:\ai小说`，小说资料保存在 `F:\ai小说\data`。

便携版不包含在此 ZIP 中，单独文件位于项目 `release` 文件夹。首次打开不会下载模型或调用云端 API；默认模型服务是本机 Ollama，需自行安装并配置模型后才能生成。连接本机以外的模型服务时，每次测试或生成前都会显示资料发送确认。

此版本未使用代码签名证书，Windows 可能显示“未知发布者”提示。若 F 盘不存在，请先连接/启用 F 盘；脚本会停止，不会改写其它磁盘。
