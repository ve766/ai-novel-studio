# AI 小说创作平台：桌面版设计

**状态：** 首个 Windows x64 版本已实现；这是当前实现边界，不是后续路线图。

## 目标

为个人长篇小说创作提供本机优先的桌面工作台。模型只生成文字，Skill 提供可选的写作方法，软件负责管理项目资料、连续上下文、创作候选和正式成果。作者保留最终决定权；不自动训练或下载模型，不隐式调用云端，也不把作品管理做成复杂 Agent 或预算平台。

## 结构与数据流

Electron 主进程负责 IPC、文件对话框、本地 JSON 存储、系统密钥库及模型请求；隔离的 React 渲染进程只经由白名单 preload API 访问功能。Ollama 和 OpenAI 兼容接口共享同一请求层，支持流式输出、超时、取消与错误处理。远程请求在测试或生成前必须显示资料传输确认。

项目资料包含章节、人物、设定、剧情线索与笔记。提示词构建器按作者选择，将任务、上下文片段和已勾选 Skill 组合成可预览的单次请求。章节工作草稿、正式正文和正式正文编辑缓冲分开保存；模型结果先作为候选，只有作者采纳后才改变草稿或正式正文。正文历史、项目备份、可恢复归档和导入引用映射共同保护长期作品。

## 视觉与验证

界面采用“纸上编辑部”方向：暖纸色、墨绿与砖红，Newsreader 标题字与 DM Sans 正文字，章节列表和写作区维持高密度但清晰层级。测试使用临时本地数据与模拟响应，不访问真实模型或云端。发布须通过离线回归测试、生产构建、Electron 归档核验与 Windows 安装启动检查。
